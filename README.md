# 🚀 نظام إنجاز | Enjaz Task Management System

نظام متكامل لإدارة المهام وتوزيع التكليفات داخل فرق العمل. مبني باستخدام تقنيات **MERN Stack** (MongoDB, Express, React, Node.js)، ويتميز بواجهة مستخدم عصرية ومتجاوبة بالكامل لتسهيل متابعة إنجاز المهام اليومية للمدراء والموظفين.

## ✨ المميزات الرئيسية (Features)

* **نظام صلاحيات متقدم (RBAC):**
    * **المدير (Admin):** إضافة المهام، وتوزيع التكليفات على الموظفين، والاطلاع على جميع المهام وقائمة فريق العمل.
    * **الموظف (Worker):** إضافة مهام شخصية خاصة به، والاطلاع على التكليفات الإدارية الموجهة له فقط.
* **إدارة المهام (Task Management):** * إنشاء، حذف، وتعديل حالة المهام (قيد التنفيذ ⏳ / مكتملة ✅).
    * تحديد مواعيد التسليم (Deadlines) مع مؤشرات بصرية للمهام المتأخرة.
* **نقاشات مباشرة (Live Comments):** نظام تعليقات مدمج داخل كل مهمة لتسهيل التواصل بين المدير والموظف المسؤول.
* **لوحة تحكم ذكية (Smart Dashboard):** فلاتر سريعة للبحث (الكل، قيد التنفيذ، المكتملة، المهام الشخصية، تكليفات الإدارة).
* **تصميم متجاوب (Responsive UI):** واجهة مستخدم سلسة تدعم شاشات الموبايل والكمبيوتر باستخدام Tailwind CSS.
* **أمان عالي (Security):** تشفير كلمات المرور باستخدام `bcryptjs` ومصادقة المستخدمين عبر `JWT`.
